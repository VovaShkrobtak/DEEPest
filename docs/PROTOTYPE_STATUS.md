## Реализовано и проверено — разные статусы

Модельные коэффициенты имеют статус **assumption**, не experimentally calibrated. Формулы, SI-единицы, ограничения и качественные тестовые fixtures описаны в [physiology](models_physiology.md), [environment](models_environment.md), [items](models_items.md), [world](models_world.md). Полная матрица A–G целевого ТЗ 08 **не пройдена**; выше перечислен фактический срез.

Публичный API модуля типизирован; внутренние сериализуемые данные — Dictionary с проверкой схемы. Специализированные Quantity/value objects и вынос всех определений/нарративов в отдельные data-каталоги остаются инженерной задачей. Ядро не зависит от Node/SceneTree/UI/OS/IO. World использует публичный контракт Physiology для тех же правил организма NPC; это явная односторонняя зависимость.

Локальный прогон на Linux включает проверку импортируемости Godot 4.6.3, архитектурных границ, отдельные регрессии, сквозную ночь и пассивную 100-дневную симуляцию доменов. Последняя проверяет конечность чисел/запасов, а не способность общества прожить 100 дней. Журнал ограничен 180 записями, trace240, replay-window2048, память NPC32. Архивная история ещё не реализована.

JSON сохраняет числа с ограниченной точностью: допустимое относительное расхождение при продолжении после save/load — 1e-10 для численных полей; дискретные исходы и передачи ресурсов одинаковы. Побитовая эквивалентность произвольных разных dt не заявлена, UI всегда запрашивает кратные10с шаги. Порядок комнат сортируется, чтобы JSON-перестановка ключей не меняла последовательность событий.

## Не заявляется

Не собран и не проверен APK, нет замеров на SM-T515, Windows/Linux-native export templates не установлены. Пакет .pck и переносимый Linux-запуск с приложенным Godot runtime проверяются отдельно. Нет клинической, токсикологической или экспериментальной калибровки. Радиосообщение — фиксированный контент сценария при физически исправном включённом приёмнике, а не симуляция всех радиостанций региона.
